充実のリハビリ

「デイサービス福泊」ならびに「認知症対応型デイサービス福泊カフェ」では、症状の改善や予防のために、ご利用者様が無理なく楽しく実践できる様々なリハビリテーションを取り入れています。

REHABILITATION / 01

回想法

昔の懐かしい思い出を語り合ったりすることで脳が刺激され、精神状態を安定させる効果が期待できる療法です。当施設では、当時の様々な映画や音楽鑑賞を通じて、懐かし思い出話に花を咲かせていただきます。

REHABILITATION / 02

ドッグセラピー

ワンちゃんと触れ合う環境で、お過ごしいただきます。看板犬の「ケン君」は、とても大人しく、人なつっこい性格。一緒にレクリエーションを楽しんだりすることで、ご利用者様の癒しとなります。

REHABILITATION / 03

音楽セラピー

音楽を聞いたり演奏したりする際の生理的・心理的・社会的な効果を応用して、心身の健康の回復、向上をはかります。当施設では、ご利用者様のハーモニカ演奏に合わせて、みんなで歌を歌ったり、リズムリトミックなども行っております。和楽では、利用者様参加型で、効果的なリハビリテーションを実施しております季節のお楽しみにボランティアの演奏者に来て頂き、本格的な懐かしい歌謡曲を楽しみます。

REHABILITATION / 04

生活リハビリ

高齢者の方の「できる力」を引き出し、家庭や社会の一員としての感覚を取り戻していく生活リハビリ。当施設では、お洗濯やお料理など日常生活での作業をご利用者様にお手伝いいただくことで、社会や家庭での意欲を向上させ、「生活機能」全体の改善を促してまいります。

REHABILITATION / 05

機能訓練

専門職による機能訓練、看護師による利用者のバイタルチェック（体温、血圧などのチェック）、医療看護ケア、急変時対応などもあるため、安心してご利用いただけます。

REHABILITATION / 06

学習療法

音読と計算を中心とする教材を用いた学習を、スタッフとともにコミュニケーションを取りながら行うことで、認知機能やコミュニケーション機能、身辺自立機能などの維持・改善を図る療法です。脳を刺激するとともに、「学びたい」という意欲も向上します。
