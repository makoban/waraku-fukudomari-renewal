# WARAKU福泊 サイト全体リニューアル案

[リニューアルサイト](https://makoban.github.io/waraku-fukudomari-renewal/) · [既存とのスクリーンショット比較表](https://makoban.github.io/waraku-fukudomari-renewal/comparison/) · [サイトマップ](https://makoban.github.io/waraku-fukudomari-renewal/sitemap/) · [生成デザイン原案](https://makoban.github.io/waraku-fukudomari-renewal/design.html) · [現行サイト](https://waraku-f.jp/)

WARAKU福泊のサイト全体を対象にした、操作可能なデザイン確認用サイトです。メニューから移動する全ページを統一したデザインに変更し、過去の記事本文・投稿日・写真も引き継いでいます。配信先はGitHub Pagesです。現行の公式サイトのドメイン・サーバー・WordPressには変更を加えていません。

比較表は、主要8ページと記事・月別一覧の代表2画面について、PC・スマホで実際の表示を撮影した40枚を掲載しています。PCは1440×1000、スマホは390×844のブラウザー条件です。旧サイトの幅1200pxによる自動縮小もそのまま記録しています。2026年11月15日撮影。比較表はサイト本体とは別の追加1ページで、PNG原本・撮影記録・原本40枚のZIPも保存しています。スクリーンショットを生成画像に置き換えていません。

## 対象ページ

主要8ページは、ホーム、充実のリハビリ、デイサービス福泊、福泊カフェ、ケアプラン福泊、求人情報、スタッフブログ、会社概要です。求人情報は元サイトのトップページ内の内容を、独立したページとして読みやすく整理しました。

ブログ等の**201記事**、**55か月のアーカイブ**、過去記事一覧の20ページ、サイトマップ、生成デザイン原案ページも含め、**計286ページ**を生成しています。元サイトの通常投稿とスタッフブログの投稿は、日付を保持して一覧から閲覧できます。

- メニューとフッターから各ページへ移動できます。
- ブログはタイトル・本文の検索、月の絞り込み、ページ移動に対応します。
- 写真・図・1日の流れは拡大でき、キーボードでも開閉できます。
- デイサービスと福泊カフェの1日の流れは、元画像を確認してHTMLの文字でも読めるようにしました。
- スマホでは電話・メールのショートカットを画面下部に配置しています。
- フォント・画像はサイト内に保存し、画面幅に応じたWebPを配信します。

## 内容と写真の扱い

現行サイトのサイトマップ209URLとブログ一覧を2026年11月15日に確認しました。記事本文は原本と移行後の文字列を照合し、201件すべて一致しています。記事に掲載された461枚の写真は、記事ごとの枚数も照合しています。

施設や活動の写真、案内図、給与、送迎エリア、連絡先、営業日などは元サイトの内容を引き継いでいます。ケアプラン固有の対応時間と施設共通の営業時間は区別しています。求人の金額は「現行サイト掲載の給与」として案内し、募集状況・条件の詳細は直接の問い合わせ先に接続しています。

ダウンロードした**923画像の原本（約1.38GB）**は、ローカルの `site/assets/source/` に原本のまま保存しています。このフォルダはGit管理と公開用チェックアウトから除外しています。GitHubには表示用のWebP、出典URL、原本のSHA-256を保存しています。WebPはサイズと形式を調整したもので、顔・施設・写真の内容に生成や修整を加えていません。既存の小さな原本画像は `site/assets/original/` にも保存しています。

[元ページの取得記録](source/page-manifest.json) · [画像原本の取得記録](source/media-manifest.json) · [配信用画像との対応](source/derivatives-manifest.json) · [記事本文・写真の移行照合](qa/content-migration.json)

サイトマップに残っていた `/helperstation` は取得時に本文が空でした。実在のサービス内容を新しく作ることはせず、公開中の内容のあるページを対象に再構成しています。出典記録は、第三者への素材利用許諾を意味するものではありません。

## ローカルで見る・再生成する

```sh
python3 -m http.server 8798 --bind 127.0.0.1 --directory site
```

`http://127.0.0.1:8798/` を開きます。閲覧時はビルド・外部API・データベース不要です。GitHub Actionsは `site/` をGitHub Pagesに配信します。

再生成用のPython依存は `beautifulsoup4` と `pillow` です。原本がない場合は先に `scripts/collect_site.py` を実行し、画像軽量版は `scripts/prepare_site_media.py`、ページは `scripts/build_site.py`、フォントは `scripts/prepare_fonts.py` の順に準備します。`scripts/check_site.py` でリンクと内容を検証できます。大きな原本の取得・画像変換は1件ずつ処理し、CPU優先度と読取帯域を抑えて実行します。
