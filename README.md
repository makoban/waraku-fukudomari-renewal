# ケアプラン福泊 リニューアル案

[確認用ページ](https://makoban.github.io/waraku-fukudomari-renewal/) · [gpt-image2のデザイン原案](https://makoban.github.io/waraku-fukudomari-renewal/design.html) · [現行のページ](https://waraku-f.jp/careplan)

既存のケアプラン福泊ページをもとにした、操作可能なデザイン確認用サイトです。現行サイトのサーバー・ドメインには変更を加えていません。対象はケアプラン福泊の1ページで、その他のページへのリンクは現行サイトに接続しています。

## デザイン

落ち着いた緑とテラコッタ、明朝体の見出し、読みやすいゴシック体で構成。スマホでは電話・メールへのリンクを画面下部に表示します。写真・案内図は拡大表示でき、メニューと拡大表示はキーボードでも操作できます。

内蔵 `image_gen`（gpt-image2指定、契約プラン内）で計3点を生成しました。

1. 相談シーンのイラスト
2. ご家族との相談シーンのイラスト
3. 文字・数字を含むページ全体のデザイン原案

生成した人物はイメージです。実際のスタッフ・利用者の写真ではありません。掲載箇所には「AI生成イラスト」と明記しています。架空の施設写真、実績、口コミ、料金、資格、対応時間、無料相談等は追加していません。デザイン原案に含まれる施設写真部分は生成画像のため、動くページではダウンロードした原本に差し替えています。

[生成指示全文](design/prompts.md) · [生成原本](design/generated/) · [元画像と出典の対応表](source/assets-manifest.json)

## 情報と写真

2026年11月15日に現行サイトを確認しました。

| 内容 | 出典と扱い |
| --- | --- |
| 介護相談窓口、ケアプランの提案、申請代行 | [ケアプラン福泊](https://waraku-f.jp/careplan)の情報を整理 |
| 電話、メール、郵便番号、住所、FAX | 現行ページの共通案内を継承 |
| 営業日・営業時間 | [会社概要](https://waraku-f.jp/company)と共通フッターの施設案内を継承。ケアプラン固有の対応日時とは区別 |
| 外観写真・施設案内 | 現行ページの `foot_image.jpg` を原本のまま保存。サムネイルは軽量WebP、拡大時は原本 |
| 畳の廊下の写真 | [現行トップページ](https://waraku-f.jp/)掲載の画像を保存。写真の内容は変更せず、軽量WebPと原本を利用 |
| 案内図・会社ロゴ・旧イラスト | 現行サイトから原本を保存。案内図は拡大表示、会社ロゴはフッターで利用 |

出典URLと保存データのSHA-256は対応表に記録しています。元画像・生成原本は維持しています。素材の出典記録は第三者への利用許諾を意味しません。

## 確認

- Chromiumで幅 **320 / 360 / 375 / 390 / 393 / 412 / 430 / 768 / 1024 / 1440px** を確認。
- 全幅でページ横スクロール、主要要素の親枠からのはみ出し、保護した語句のはみ出しが0件。全画像の読み込み成功、JavaScriptエラー0件。
- スマホの端末倍率2・PC倍率1で、選択された画像と転送量を記録。390px・1440pxでは画像とフォントの本文サイズの合計は約319KB（ページ全体をスクロールして遅延画像を含めた値、原本拡大前）。先頭のイラストは約64KBの800px WebPを選択。
- メニュー、ページ内リンク、写真・案内図3点の拡大、Escape・閉じるボタン・背景クリック、閉じた後のフォーカス復帰を確認。
- 電話・メールのリンク先を照合。実際の電話発信・メール送信は行っていません。
- デザイン原案ページは320pxの表示と画像読み込みを確認。
- LP品質チェック、JavaScript構文チェックに合格。

[画面幅ごとの検証記録](qa/responsive-audit.json) · [画像・フォントのサイズ](qa/asset-sizes.json)

ブラウザによる確認であり、実機のiPhone・Androidによる操作確認は未実施です。確認用URLはインターネットから閲覧できます。`noindex` と `robots.txt` は検索エンジンへの掲載を抑制するもので、閲覧制限ではありません。

## ローカルで見る

```sh
python3 -m http.server 8798 --bind 127.0.0.1 --directory site
```

`http://127.0.0.1:8798/` を開いてください。ビルド・外部API・データベースは不要です。フォントもサイト内に保存しています。配信対象は `site/` のみです。

素材の軽量版を作り直す場合は、Python 3と `cwebp` を用意して `python3 scripts/prepare_assets.py` を実行します。フォントのサブセットはGoogle Fontsから取得し、それぞれのOFLを `site/assets/fonts/` に同梱しています。
